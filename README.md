# Rikhin Kavuru Portfolio - Technical Brutalist v2.0.26

A premium, high-performance personal portfolio designed with a **Technical Brutalist** aesthetic. This site highlights a unique blend of computational research, full-stack development, and organizational leadership.

## 🚀 Vision
Built for the 2026 era, this portfolio rejects standard "AI-clean" aesthetics in favor of a raw, functional, and highly precise interface. It utilizes a deep obsidian color palette with **Neon Amber** high-voltage accents and a visible grid system to reflect a "research-first" mindset.

## 🛠 Tech Stack
- **Core**: Semantic HTML5 & Vanilla JavaScript
- **Styling**: Pure CSS3 (Technical Brutalist Design System)
- **Features**:
    - **Terminal Hero**: Dynamic typing effect for role rotation.
    - **Bento Stats**: A modular grid for academic performance (SAT, AMC, APs).
    - **Mouse-Follow Glow**: A dynamic light effect that follows the user's precision.
    - **Glassmorphic UI**: High-end transparency and blur effects on interactive project cards.

## 📂 Structure
- `index.html`: Core structure and content.
- `style.css`: Design tokens, grid system, and layout.
- `script.js`: Interactivity, animations, and typing engine.
